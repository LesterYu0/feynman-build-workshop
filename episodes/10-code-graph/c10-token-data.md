## 诚实边界（⚠️ 必读）

- **121x 是峰值，10x 是均值** —— 不同问题类型差异巨大，别被峰值唬住
- 31 个真实仓库的严格评估才是代表性数字
- 首次索引有成本：索引时间 / 磁盘占用 10-30% / 内存峰值
- 精度 83-90%，不是 100% —— Hybrid 策略（先查图，查不到再读文件）补足

## 为什么能省这么多

```
传统：grep → read → grep → read 循环（每轮都要模型读文件）
图谱：AI 直接问图（search_graph / trace_path / get_architecture）

```
