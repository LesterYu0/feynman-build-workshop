## 核心结论

**你的 AI 编程助手不是不聪明，是缺一张代码地图。** 它现在的探索方式是 grep → read → grep → read 循环——一个"这个函数被谁调用了"的结构性问题，能烧掉 41 万 Token、10 轮工具调用，还可能遗漏关键依赖。

codebase-memory-mcp 把代码库索引成一张**知识图谱**：函数、类、调用链、数据流、HTTP 路由全部变成图里的节点和边。AI 需要了解代码结构时不再逐文件翻，而是**直接问图**——同样的结构性问题从 41 万 Token 降到 3400，**121 倍差距**（峰值；均值 10x）。

关键不是「给 AI 更大的上下文窗口」，而是「给 AI 一张地图」：**索引一次，反复查询，亚毫秒响应。**
