# C08 · 多模型路由选型决策表 + 生产 Checklist

## 选型决策表

| 场景 | 策略 | 说明 |
|------|------|------|
| 送分题 / 高频查询 | 单便宜模型 | 路由直接秒回，不组队 |
| 开放推理 / 多正确路径 | 组队 3–5 家 + 共识聚合 | 多样性采样互补软肋 |
| 要求格式严格一致 | 组队 + 归一化后聚合 | 防标点 / 空格导致平局 |
| 预算敏感 | Router 阈值调严，少组队 | 贵智能只花在难题 |

## 生产环境 Checklist

- [ ] 每个 Provider 的 `call()` 都用 try/except 包裹，失败返回 `[FAILED]` 提案（坑 1）
- [ ] Ensemble 用 `as_completed(timeout=...)`，超时降级（坑 2）
- [ ] 聚合前过滤 `ok == False` 或空文本（坑 3）
- [ ] 投票前 `strip().lower().rstrip("。.!！?？")`（坑 4）
- [ ] 难度判断走廉价规则（长度 / 关键词），别用大模型（坑 5a）
- [ ] Router 阈值按预算调；跑账单确认简单题未无脑组队（坑 5b）
- [ ] 接真实模型只需实现 `_generate()`，返回 `Proposal(text, cost, ok)`
- [ ] 监控：记录每题走单模型 vs 组队的比例与成本，定期回看路由阈值
