# ⑦ 评测 Checklist（造物工坊 #C09）

> 三层评测（Agent GPA 思路）：L1 推理层 → L2 行动层 → L3 执行层。
> 评测要**自动化**成回归测试，每次改 Plan 逻辑都跑一遍，别靠肉眼。

## 核心指标 + 阈值（不及格线）
| 指标 | 阈值 | 说明 |
| --- | --- | --- |
| Plan Coherence | **= 1.0** | 计划有循环即废 |
| Tool Call F1 | **≥ 0.92** | 工具选对 + 参数对 |
| 首次成功率 | **≥ 0.85** | 一次跑通的比例 |

## 六问 Checklist（每次交付前过一遍）
- [ ] ① 计划无循环、无逻辑矛盾
- [ ] ② 工具选择正确（名称/语义）
- [ ] ③ 参数格式正确（类型/必填项）
- [ ] ④ 首次成功率达标（≥ 0.85）
- [ ] ⑤ replan 次数可控（能 Retry 兜住的别 Replan）
- [ ] ⑥ 成本在预算内（token / 时长）

## 三层漏斗怎么用
```
Goal
 └─ L1 推理层：过滤「规划混乱 / 有循环 / 步骤矛盾」的计划
     └─ L2 行动层：过滤「工具选错 / 参数错」的执行
         └─ L3 执行层：看首次成功率、平均步数、成本
             哪层漏了，往哪层补
```

## 自动化建议
把三层做成回归测试集，CI 里每次改 Plan 逻辑自动跑；
低于阈值直接红，防止「以为优化了其实退步了」。
